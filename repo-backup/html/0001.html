    Add regex-syntax for standard regex parsing while refactoring the existing custom parser to remove nom.

    This PR introduces a new Re::parse_regex method that leverages the regex-syntax crate for parsing standard regular expressions. Concurrently, the existing Re::parse method, which handles a custom grammar, has been refactored to remove its nom dependency, maintaining 100% backward compatibility and passing all original tests. This provides dual parsing capabilities and modernizes the regex parsing infrastructure.
